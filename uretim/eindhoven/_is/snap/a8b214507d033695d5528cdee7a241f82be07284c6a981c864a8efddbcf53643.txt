Apply for a DigiD
With your DigiD you identify yourself when you arrange matters online. Such as with the government, educational institutions, healthcare or your pension. Apply for your DigiD via the application form.
Apply via the application form
What do I need?
For your DigiD application you will need the following:
Citizen service number (BSN)
Registration address with a Dutch municipality
Mobile phone
If you applied for a DigiD you will receive a letter with an activation code by post. You will receive this letter within 3 business days on the address where you have registered with your municipality.
Please note: Your DigiD is personalized. You are not allowed to apply for a DigiD that is meant for someone else. If you want to help someone else arrange matters online, you can use Authorisation.
No permanent home address or not registered in the Dutch BRP
If you do not have a permanent home address and are also not registered in the Dutch BRP (Personal Records Database). Because, for example, you reside in a care facility or prison. You can still apply for a DigiD. You can register with your municipality at a postal address.
Please note: The postal address cannot be a PO Box or an empty address.
Registration in the BRP
Anyone residing lawfully in the Netherlands must be registered in the BRP. This can be with a home address or with a postal address.
Read more about the BRP at Government.nl
Postal address
A postal address is an address where documents sent by the government are received for you. This must be an existing address of a person or institution; the so-called ‘postal address host’. A postal address host must ensure that government post, such as a tax form, voting pass or summons, reaches you.
For more information on a postal address, please contact your municipality.
How does it work?
Application for a DigiD
DigiD application form
You will need your citizen service number for the application.
Click on the button or go to digid.nl/en/aanvragen.
Fill in your details and complete your application.
Remember your username and password, because you will need them to activate your DigiD. Following your application, you will receive a letter with an activation code within a maximum of 5 working days. How long it takes depends on the mail delivery in your region.
Please note: The letter will be send to the address where you are registered at your municipality in the Dutch Personal Records Database (BRP). If something is wrong, please contact your municipality
I live in the Caribbean Netherlands or abroad
Do you live on Bonaire, Sint Eustatius, Saba, or abroad? And do you have a citizen service number (BSN)? Then you can apply for a DigiD via the DigiD application form.
Have you moved to the Caribbean Netherlands or abroad and did you already have a DigiD before that? Then you can continue to use your DigiD.
Read more about applying for a DigiD when you live in the Caribbean Netherlands or abroad.
For your child
Younger than 14 years old
Parents and guardians are allowed to help their child with the age of 13 and under with applying for and using a DigiD. Fill in their personal data during the application process.
Apply for a DigiD on behalf of your child
DigiD will send a letter with an activation code within 3 working days. The letter will be sent to your child personally on the address where your child is officially registered. This is how DigiD checks the identity of your child. It is not possible to change the address on which to receive the letter.
14 years or older
Children from the age of 14 need to apply for a DigiD by themselves. From that age a DigiD is strictly personal. Your child can apply for a DigiD via the website.
It did not succeed
Verification code SMS message not received
Verify that the code was sent to the correct phone number. Did the code really not arrive properly? Then you can request a new code after one minute.
Get a call
We can also call you. Then you will be told the SMS code. This sometimes works better than regular texting, especially outside the Netherlands.
From the DigiD login screen, select ‘No code received?’
Select ‘Call me with a voice SMS message’
You will then be called and receive a voice SMS message.
It still does not work
Phone signal: Check that you have a sufficiently strong mobile phone signal. If you do not, try to go to spot where you have a sufficient signal.
Turn your phone off and on: Switch your mobile phone back on so that it reconnects to your telecommunications provider’s mobile network.
Check your telecommunications provider’s website to see if there are any failures. Does this not help? Please contact your telecommunications provider, stating the date and time when the SMS code should have been received. Then your telecommunications provider can do targeted research.
Verification code via email not received
Did you not receive the verification code via email? There may be several reasons for this.
The email address provided is incorrect.
The verification code email has been saved to your junk post folder.
Your junk email settings are blocking the receipt of the email.
Your ISP service is down.
If there is no demonstrable reason, you can skip the step for adding an email address by clicking skip check. After you have activated your DigiD, you can add and confirm the email address.
Code is not accepted
Perhaps you entered an incorrect verification code.
Verifiction code via e-mail always begins with an 'E'.
Verification code via SMS consists of 6 digits.
Activation code: enter the activation code exactly as it is printed in the DigiD letter. This code always starts with an 'A'.
Please note: use the last code received. Please check the date on the letter.
Unable to understand voice SMS or too few digits
Unable to understand
Unable to understand the voice SMS verification code? This may be because you have not activated ‘Voice SMS’ in ‘My DigiD’. If you do not have this activated, your telecommunications provider automatically reads the SMS messages out loud, making it hard to understand the SMS code.
Solution: Activate Voice SMS in My DigiD. DigiD will create a voice SMS for you.
Too few digits in voice SMS
A DigiD voice SMS code always consists of 6 digits. When you receive a voice SMS code with less than 6 digits, your voicemail is enabled.
If you have voice text messaging set up, you will be called by an automated system that reads the SMS code aloud. This system does not see if you have voicemail enabled. The system starts reading out the SMS code the moment a telephone connection is made. As a result, you will only hear the last digits.
Solution: Turn off your voicemail.
Notification
DigiD application not possible in the DigiD app
Please apply for DigiD using a different browser. The DigiD app may not work properly in some browsers. To ensure that you can log in, it is best to use one of the following browsers: Chrome, Firefox, Edge, Safari (Apple).
If this does not resolve the issue, please try again at a later time.
