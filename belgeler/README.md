# Belgeler — ne nerede

| Klasör | İçerik |
|---|---|
| `durum\` | Gün sonu durum özetleri (`DURUM_<tarih>.md`). En yenisi kaldığımız yeri anlatır. |
| `tarifler\` | Yeni ülke / şehir açma tarifleri (Almanya, İspanya, genel). |
| `kilavuz\` | Kullanma kılavuzları (hibrit skill) ve kılavuz analizleri. |
| `dis_denetim\` | Atınç'ın dış denetim raporları (PDF). |

Proje kökünde başka yerler:

| Klasör | İçerik |
|---|---|
| `uretim\<şehir>\` | Şehir üretimi; durum her zaman `manifest.json` → `next_step`. |
| `denetim\<şehir>_<tarih>_<kademe>\` | city-audit çıktıları; özet `DENETIM_OZETI.md`. |
| `ulke\<ülke>\` (+ `bolge\`) | Ülke ve eyalet paketleri. |
| `ekler\` | Berlin örneği, şablon ve şehir şablonları. Araçlar bu düzeni okur, taşıma. |
| `corteqs-skills\`, `.claude\skills\` | Skill'ler (ikisi eşit tutulur). |
| `araclar\` | Paylaşılan araç kutusu. |

Kullanılmayan eski dosyalar proje dışında: `C:\temp_private\corteqs\_kullanilmayan\`.
